# RNA-seq and IMC Analysis for Bever KM and Huff AL et al.

This repository contains analysis scripts for RNA sequencing (RNA-seq) and imaging mass cytometry (IMC) data associated with the manuscript:

**Bever KM, Huff AL, et al.** *Phase II study of CRS-207/GVAX + Ipilimumab/Nivolumab in metastatic pancreatic ductal adenocarcinoma (PDAC)*

## Overview

These scripts were developed to support integrated immunogenomic analysis as part of the clinical study. Specifically, they cover:

- **RNA-seq**: Transcriptomic analysis of tumor biopsies.
- **IMC**: Spatial analysis of the tumor microenvironment.

## Data Availability

- **Raw RNA-seq data**: Available under restricted access in dbGaP under accession code **[phs003798.v1](https://www.ncbi.nlm.nih.gov/projects/gap/cgi-bin/study.cgi?study_id=phs003798.v1.p1)**. 
- **IMC data**: Publicly available via Zenodo at [https://doi.org/10.5281/zenodo.15320196](https://doi.org/10.5281/zenodo.15320196).

## Code Availability

This repository provides scripts and workflows used for:

- Differential expression and enrichment analysis
- IMC spatial and clustering analysis

The complete codebase is hosted at: [https://github.com/wjhlab/J1790](https://github.com/wjhlab/J1790)
